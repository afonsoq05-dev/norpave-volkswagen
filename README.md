# Norpave Volkswagen | Academia Comercial

Aplicativo web independente para treinamento da equipe comercial Norpave Volkswagen.

## Publicação
O site utiliza `index.html` na raiz do repositório. Para publicar com GitHub Pages, acesse **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e a pasta `/ (root)`, e salve.

## Escopo
- Catálogo inicial de veículos Volkswagen 0 km (lista preliminar, sujeita à validação do portfólio Norpave)
- Conhecimento de produto e argumentação comercial
- Orientações de vendas diretas
- Processo de vendas
- Objeções e negociação
- Avaliação interativa

## Validação
Dados técnicos, versões, preços, disponibilidade, condições comerciais e critérios de elegibilidade devem ser confirmados nas fontes oficiais Volkswagen e nos sistemas internos vigentes da Norpave antes de serem utilizados com clientes.
